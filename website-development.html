Course 03

Website Development

Planning and building websites using HTML and CSS, with attention to structure, navigation and user experience.

Course overview

This course introduces the foundations of creating websites. It involves structuring content with HTML, styling pages with CSS and organising information so visitors can navigate a site easily.

Skills developed

  • Creating pages with semantic HTML elements.
  • Building navigation between related pages.
  • Applying CSS for layout, colour and consistent presentation.
  • Organising website files and assets.
  • Considering accessibility and usability.

Learning evidence

Purrfect Match Adoption

Created a multi-page website concept for a cat adoption service, including pages for kittens, adoption information, kitten care and contact details.

Reflection

Building a multi-page website has helped me understand how individual pages work together as one complete site. I have learned the importance of consistent navigation, clear page structure and styling. I also gained experience checking links and making sure the content is organised in a way that is easy for visitors to follow.
