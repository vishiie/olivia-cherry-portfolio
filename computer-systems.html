Course 04

Computer Systems Architecture

Understanding the hardware, software, networks and security practices that support computer systems.

Course overview

This course explores computer hardware and system components, operating environments, networking concepts, diagnostics and security. Practical labs help connect technical concepts with real computer systems.

Skills developed

  • Identifying key computer components and understanding their roles.
  • Using diagnostic and troubleshooting tools.
  • Observing network traffic and protocols with Wireshark.
  • Learning about firewalls, logging and system security.
  • Documenting practical work and technical findings.

Learning evidence

  • Computer hardware lab work and component research.
  • Networking protocol investigation using Wireshark.
  • Firewall exercises involving Windows tools and security logs.

Reflection

This course has helped me better understand what happens behind the scenes when using a computer and connecting to a network. Practical troubleshooting has shown me the value of gathering evidence, checking settings and following a logical process. The networking and firewall activities have also introduced me to important aspects of protecting computer systems.
